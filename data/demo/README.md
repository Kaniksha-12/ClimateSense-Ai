# DEMO ONLY — NOT REAL CLIMATE PERFORMANCE

These files are deterministic synthetic fixtures generated by `scripts/generate_demo_dataset.py`.
No measurements were collected from weather stations, satellites, or historical flood events.
The feature values occupy plausible-looking numeric ranges only. The binary `flood_risk` labels
are sampled from an invented mathematical rule to exercise the software pipeline; the rule is
not a scientific flood model and has no physical or empirical validation.

- `synthetic_flood_demo.csv`: 240 labeled training examples for a stratified holdout test.
- `synthetic_flood_final_test.csv`: 120 labeled examples from an independent seed; keep it out of cross-validation and tuning.
- `unseen_observations.csv`: 12 generated feature-only rows, excluded from training and evaluation.
- Features: `rainfall, temperature, humidity, pressure, wind_speed`.
- Target: `flood_risk` (0/1), present only in the labeled file.

Never cite model metrics or predictions from these files as real climate performance. Replace the
labeled CSV with the real processed dataset when it is available; the ML architecture and CLI
remain unchanged.
